# HR Insight Dashboard

A responsive, frontend-only HR dashboard built with React, Vite, Recharts, Lucide React, and plain CSS. It uses local sample data and does not require a backend or database.

## Requirements

- Node.js (LTS recommended)
- pnpm

## Run the project locally

1. Open a terminal in the project folder.
2. Install the dependencies:

   ```bash
   pnpm install
   ```

3. Start the Vite development server:

   ```bash
   pnpm dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:5173`) in your browser.

## Other useful commands

Build an optimized production version:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```

Run ESLint:

```bash
pnpm lint
```
